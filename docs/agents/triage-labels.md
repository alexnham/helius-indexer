# Triage labels

| Role / label | Meaning |
| --- | --- |
| needs-triage | Requires maintainer evaluation |
| needs-info | Waiting for clarification |
| ready-for-agent | Fully specified for agent implementation |
| ready-for-human | Requires human implementation |
| wontfix | Will not be actioned |

Readiness labels describe specification readiness.
Check blocking relationships separately before starting work.
